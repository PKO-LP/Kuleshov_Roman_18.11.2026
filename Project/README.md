# Трекер расходов (Tkinter GUI)

Простое оконное приложение на Python с использованием библиотеки Tkinter для учёта покупок и их стоимости, а также планирование его разработки по диаграмме Ганта.

## Функционал приложения
- Отображение тематического изображения в верхней части окна (`PhotoImage` + `Label`).
- Ввод названия покупки и её стоимости в рублях (`Entry`).
- Добавление покупки по кнопке.
- Визуальная стилизация счётчика покупок (рамка `solid`).

## Как запустить проект
1. Убедитесь, что в папке с проектом находятся следующие файлы:
   - `app.py` — основной код программы;
   - `wallet.png` — изображение для интерфейса приложения;
   - `README.md` — описание проекта.
2. Запустите файл `app.py` через терминал или редактор кода:
   ```bash
   python app.py
   ```
